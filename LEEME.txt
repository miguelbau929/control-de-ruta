CONTROL DE RUTA - PAQUETE COMPLETO

Archivos incluidos:
- index.html: aplicación completa.
- manifest.json: configuración para instalarla como aplicación.
- sw.js: funcionamiento sin conexión y actualización de la versión.
- icon-192.png e icon-512.png: iconos de la aplicación.

PARA ACTUALIZAR GITHUB PAGES:
1. Abre el repositorio control-de-ruta.
2. Entra en Code y elige Add file > Upload files.
3. Selecciona TODOS los archivos de esta carpeta y súbelos a la raíz del repositorio.
4. GitHub debe preguntar si deseas reemplazar index.html, manifest.json, sw.js y los iconos existentes: confirma los reemplazos.
5. Confirma (Commit changes).
6. Espera la publicación y abre https://miguelbau929.github.io/control-de-ruta/ .

IMPORTANTE SOBRE LOS DATOS:
- La aplicación guarda datos localmente en cada teléfono; no sincroniza entre teléfonos.
- Antes de actualizar, descarga un respaldo desde Corte.
- El código conserva la clave local controlRutaPWA_v1 para que una actualización no cambie el espacio local de datos de esta aplicación.
- Eliminar historial pagado no borra clientes ni saldos pendientes. Reiniciar saldos es una acción separada y requiere confirmación.
